# Cooperative Gig Services Platform for Household & Community Services

A cooperative-owned digital service marketplace connecting verified skilled workers belonging to Labour Cooperative Societies/Federations with Customers, Households, Institutions, and Large Projects.

## Roles

- `SUPER_ADMIN`
- `FEDERATION_ADMIN`
- `WORKER`
- `CUSTOMER`

## Unified Architecture

This project is built as **ONE** unified Next.js application containing all 4 roles, sharing common authentication, RBAC, design system, database models, and core business services.
